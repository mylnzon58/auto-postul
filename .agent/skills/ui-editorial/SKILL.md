# UI editorial

## Estilo

- Papel cálido, tinta, verde profundo.
- Sin gradientes, sin neón, sin vidrio, sin morado, sin emojis.
- Tipografía de sistema; serif solo para títulos.
- Bordes de 1px, radios de 6px, sombras mínimas.
- Espaciado en escala de 4/8/12/16/24/32.

## Producto

- Máximo 3 acciones primarias por pantalla.
- Una tarea principal por vista.
- Divulgación progresiva.
- El termómetro muestra número, etiqueta y razones.
- Estados vacíos con próxima acción clara.
- Mensajes en español, directos, sin culpar al usuario.

## Accesibilidad

- HTML semántico.
- Labels asociados.
- Foco visible.
- Contraste AA.
- No usar color como única señal.
- Respetar `prefers-reduced-motion`.
- Formularios usables con teclado.
