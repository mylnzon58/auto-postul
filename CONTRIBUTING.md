# Contribuir

1. Leer `AGENTS.md`, `docs/arquitectura.md` y los ADRs.
2. Crear una rama.
3. Cambiar código con tests.
4. Ejecutar `make check`.
5. Actualizar documentación.
6. Abrir un pull request con una descripción corta.

No incluir CV reales, `.env`, bases SQLite, capturas de LinkedIn ni credenciales.

Las decisiones estructurales nuevas requieren un ADR en `docs/decisiones/`.
